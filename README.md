# Projekt
### **Zakres materiału**

1. Zrealizowane funkcjonalności:  
        -    (1 pkt za 1 funkcjonalność, max 15 pkt)   
        - funkcjonalności mają spełniać praktyki wydajnego programowanie w .net: wzorzec repozytorium, dto itd.  
        -    Do jednej funkcjonalności zaliczane są operacje CRUD (np. tworzenie, aktualizacja, wyświetlanie i usuwanie kategorii)
2. Wdrożenie modeli z wykorzystaniem relacji ManyToMany (przynajmniej 1) i OneToMany . Ok 20 modeli/encji (6-7 os.) z wykorzystaniem ORM (w zależności od zaawansowania i skomplikowania relacji w bazie danych: max 10 pkt) – **tabele biblioteki**
3. Realizacja uwierzytelniania z wykorzystaniem modułu ClaimsIdentity. Projekt powinien wspierać przynajmniej dwie role: użytkownika zalogowanego oraz moderatora z wyższymi uprawnieniami. (10 pkt) – **czytelnicy, bibliotekarze**
4. Realizacja przesyłania plików na serwer lokalny lub zdalny z wykorzystaniem formatki HTML file (5 pkt). – **pobieranie ebooków z bazy bibliteki**
5. Estetyczny wygląd aplikacji (5 pkt)
6. Dokumentacja i jej użyteczność (2 pkt)
7. Testy automatyczne (max 8 pkt). Pokrycie testami 70-80% głównej logiki aplikacji (bez zapisów do ORM)
8. Wdrożenie aplikacji na produkcji (max 5pkt) – **Azre?**
9. Zastosowanie zewnętrznego API np. pobranie prognozy pogody,  zastosowanie OpenAI, płatności itp. (max. 5 pkt) – **płatności za opóźnione książki**
10. Aplikacja webowa powinna stosować jedną z zapoznanych w trakcie studiów architektur projektów IT np. architekturą warstwową, wykorzystującą wzorce Repository, Dependency Injection oraz Data Transfer Object (DTO) dostosowaną do wymagań biznesowych, skalowalności i złożoności systemu.

Dodatkowo:

1. Aplikacja posiada obsługę formularzy do wyświetlania, usuwania, dodawania i edycji elementów – **zarządzanie książkami**
2. Aplikacja posiada moduł logowania, obsługuję autoryzację użytkownika – **biblitekarze, czytelnicy**
3. Aplikacja odwołuje się do Api zewnętrznego (pogoda, kursy, akcje, autoryzacja google/fb) – **płatności** 
4. Aplikacja udostępnia interfejs API – **dostępnych ebooków w bibliotece?**
5. Aplikacja posiada bazę danych oraz przechowuje trwale informacje – książki
6. Liczność encji niesłownikowych przekracza 7/osoba w grupie - minimalna ilość encji ogółem wynosi 10/osoba – książki
7. Aplikacja jest przejrzysta i estetyczna (zastosowanie zmian w stylowaniu)
8. Aplikacja obsługuje załączniki (w formularzach oraz umożliwia pobieranie plików) 
9. Aplikacja Generuje dokumenty (np.: pdf, excel, word) - można wybrać 1 typ dokumentu – **excel z listą wypożyczeń czytelnika?**
